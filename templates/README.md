# Deployment templates

The templates in this directory deploy Corto from this repository. They intentionally build the existing multi-stage `Dockerfile`; no unpublished container image is required.

| Platform | Compose file                                                 | How to use it                                                                                                  |
| -------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| Dokploy  | [`dokploy/docker-compose.yml`](dokploy/docker-compose.yml)   | Git-backed Docker Compose project; configure the values generated by [`template.toml`](dokploy/template.toml). |
| Coolify  | [`coolify/docker-compose.yaml`](coolify/docker-compose.yaml) | Git-backed Docker Compose build pack with the Compose Location set to this file.                               |

Both templates create PostgreSQL and Redis inside the deployment and expose only Caddy on port `80`. For a shared or managed database and Redis, use the root `compose.yaml` and set `DATABASE_URL` and `REDIS_URL` yourself.
